# Nota

Esta carpeta contiene los planos de construcción que necesita el mod.

# Tutorial

Abre el juego y pulsa la tecla de acceso rápido `F8` para abrir la carpeta de partidas guardadas.

En `TerritoryArchive\UserData\build_blueprint`, busca el plano que quieras compartir y cópialo en la carpeta `BuildBlueprint` del mod.

Cuando otro jugador active el mod, podrá ver el plano de construcción que compartiste.
