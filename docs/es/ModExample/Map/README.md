# Nota

Esta carpeta contiene los mapas personalizados que necesita el mod.

# Tutorial

Abre el juego y pulsa la tecla de acceso rápido `F8` para abrir la carpeta de partidas guardadas.

En `TerritoryArchive\UserData\map`, busca el mapa personalizado que quieras compartir y cópialo en la carpeta `Map` del mod.

Cuando otro jugador active el mod, podrá comenzar una partida nueva en el mapa que compartiste.
